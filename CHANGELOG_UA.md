# Історія змін

[English](CHANGELOG.md) · Українська

## 0.1.2

- Дозволено `ImpMode=Edit` разом із `All` у режимі `ui` зі збереженням API 1,
  повного XML у `ctx.commit_xml()` та `write_scope=sheet_settings`.
- Час зміни XML-файлу обміну при публікації результату збільшується щонайменше
  на дві секунди; за відсутності змін файл не перезаписується.
- Додано перевірку часу зміни та розміру початкового XML разом із SHA-256,
  щоб виявляти зовнішній перезапис навіть без зміни вмісту.
- Для режиму `ui` дерево процесів Python контролюється через Windows Job Object;
  фонові завдання `job` залишаються незалежними.
- Додано профіль генератора `--profile stamp` з `ImpMode=Edit`, `Stamp=Yes`,
  `Patterns=No` та вимкненими іншими категоріями імпорту.
- Розширено регресійні тести й оновлено англійську та українську документацію.

API залишається 1. Наявну реалізацію імпорту рамок у TitleJob не змінено.

## 0.1.1

- Пошук Python за коротким ім’ям у PATH перед CreateProcessW.
- Передавання аргументу Python Launcher `-3` без лапок.
- Запис команди запуску, виводу Python і помилок процесу до журналу в TEMP.
- Формування метаданих версії з `build_info.json` для Python, властивостей EXE,
  вікон повідомлень, журналів та lock-файлів залежності.
- Команда `--version`, архіви з версією в назві та перевірка актуальності збірки.
- Необов’язкова незалежна версія плагіна в назві, що відображається в DipTrace.

API залишається 1. Сумісність із наявними плагінами `main(ctx)` збережено.

## 0.1.0

Перший спільний адаптер із режимами job/UI, транзакційним поверненням XML,
Python API контексту, генератором плагінів та залежністю, закріпленою на коміті.
