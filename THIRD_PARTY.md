# Build/runtime notices

The executable is built using Zig 0.14.1 with its MinGW-w64 C runtime support.
The toolchain itself is not included. MinGW-w64 runtime notices are reproduced
in third_party/mingw-w64-COPYING.txt. Windows system DLLs are not redistributed.
Python and Tkinter are supplied by the user's Python installation.
The official DipTrace SDK/specification files are referenced, not redistributed.
